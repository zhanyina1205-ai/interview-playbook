# 詹依娜 · 面试准备

手机与电脑访问：[https://zhanyina1205-ai.github.io/interview-playbook/](https://zhanyina1205-ai.github.io/interview-playbook/)

150 道问答，包含 20 道重点题、15 个分类、搜索、收藏、掌握进度、随机自测和个人笔记。

- 手机端使用底部导航，支持安全区域和触控操作。
- 可通过浏览器“添加到主屏幕”保存入口。
- 首次在线加载并完成缓存后，支持离线复习；更新时联网刷新。
- 收藏、进度和手写笔记仅保存在当前浏览器，可单独导出；不会上传至 GitHub。
- 线上页面与仓库可公开访问，笔记不会在不同设备间自动同步。

## 更新

页面为纯静态文件，入口是 `index.html`。GitHub Pages 从 `main` 分支根目录发布。
内容由本地面试手册生成，发布包只包含网页、应用图标、清单和离线缓存脚本。
